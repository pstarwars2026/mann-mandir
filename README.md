# Mann Mandir

A quiet place for Krishna darshan, aarti, flowers and fruit offerings.

**Available for supported iPhones and iPads · Free**

[Download Mann Mandir on the App Store](https://apps.apple.com/us/app/mann-mandir/id6829619459). This is its public product, support and privacy repository. App source code and release materials are private.

- [Product page](https://pstarwars2026.github.io/mann-mandir/)
- [Support](https://pstarwars2026.github.io/mann-mandir/support.html)
- [Privacy](https://pstarwars2026.github.io/mann-mandir/privacy.html)
- [Report a problem or suggest a feature](https://github.com/pstarwars2026/mann-mandir/issues/new/choose)

No accounts, ads, analytics or in-app purchases. Shrine choices and preferences stay on-device. Supported Duo devices offer partial-open darshan and fully open puja; supported iPhones and iPads use a single-screen mandir.

GitHub Issues are public. Do not include personal information, private images or sensitive devotional details.
